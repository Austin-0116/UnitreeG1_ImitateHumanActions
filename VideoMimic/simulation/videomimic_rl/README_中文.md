# RSL RL

这是一个快速、简洁的强化学习算法实现，设计为完全在 GPU 上运行。
该代码是在 NVIDIA Isaac Gym 中提供的 `rl-pytorch` 基础上演进而来的。

目前只实现了 PPO，后续将加入更多算法。
欢迎贡献代码。

## 安装

```
git clone https://github.com/leggedrobotics/rsl_rl
cd rsl_rl
pip install -e .
```
